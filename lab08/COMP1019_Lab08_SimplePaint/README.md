# COMP1019 - Lab 08: Simple Paint

Ứng dụng Paint đơn giản sử dụng C# Windows Forms và GDI+.

## Yêu cầu
- Windows, Visual Studio 2022/2026
- Workload .NET desktop development
- .NET 8 SDK

## Cách chạy
1. Giải nén thư mục dự án.
2. Mở `COMP1019_Lab08_SimplePaint.csproj` bằng Visual Studio.
3. Nhấn `F5`.

## Chức năng
- Pen, Line, Rectangle, Ellipse.
- Chọn màu với ColorDialog.
- Độ dày nét từ 1 đến 20.
- Undo, Ctrl+Z, Clear.
- Hiển thị tọa độ chuột.
- Lưu vùng vẽ thành PNG.
