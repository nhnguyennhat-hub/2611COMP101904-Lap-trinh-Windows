# LAB 01 - ỨNG DỤNG THÔNG TIN CÁ NHÂN

## Công nghệ
- C#
- Windows Forms App
- Visual Studio
- .NET 8

## Chức năng
- Nhập họ tên, năm sinh, email.
- Chọn giới tính.
- Chọn khoa/lớp.
- Kiểm tra dữ liệu đầu vào.
- Hiển thị thông tin và tuổi.
- Xóa dữ liệu.
- Thoát có xác nhận.
